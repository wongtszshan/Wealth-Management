# 澄理 · Wealth Management

个人财富管理 PWA。以资产负债、财富变化、财务目标为主，日常收支为底层明细。当前版本 **v2.0.1**。

## 支持范围与现状
- **现金与存款**：中国、新加坡银行账户，可根据实际情况另选 USD；余额、昵称、地区、记录日期、流动性标签。
- **投资持仓**：美国股票（USD）、新加坡股票（SGD）；股票数量、单位成本、手动估值、估值日期、未实现盈亏。ETF / 基金是可选类型，**没有预设用户持仓**。
- **负债**：信用卡、贷款、房贷等未偿金额与记录日期。
- **净资产**：现金 + 持仓市值 − 负债。每个币种分别核算；跨币种汇总以 **SGD** 为展示基准，CNY→SGD、USD→SGD 汇率必须由用户手动填写。缺少必要汇率时不提供伪精确总额。
- **配置分析**：现金与股票结构、最大单一持仓、负债/资产比例；可设置每月必要支出，估算已标记可动用现金的覆盖月数。不提供无依据的财务健康分数。
- **财务规划**：目标金额、已专门预留资金、预定日期；未来单项大额支出和收入。计划不改变实际资产余额。
- **财富报告**：当前月 SGD/CNY 已录入收支汇总、净资产快照、自查清单、历史趋势及 JSON 导出；支持保存多次快照并保留历史。
- **原有功能保留**：交易流水、单笔记账、CSV、多张图片和 PDF 银行账单 AI 识别（人工核对）、月度比较、分类预算、储蓄目标、原有账户昵称、JSON / CSV 导出。

## 数据模型和防重复计算
新版存储格式为 version 2。新增 cashAccounts、holdings、liabilities、fxRates、wealthSnapshots、financialGoals、futurePayments、monthChecks、monthlyEssentialsSGD。旧交易和账户字段保留。
- 账户余额、证券持仓、负债采用**手动时点快照**；**不会**再从不完整的消费流水对这些余额进行加减。
- 银行转券商、股票交易、信用卡还款不应被误计为额外消费；目前尚无完整复式记账和自动跨账户勾稽，请谨慎分类。
- 财富估值变化不等同于投资已实现收益；月度收支结余不等同于净资产变化。
- 汇率未联网更新，股票价格也**不**自动从行情服务获取。估值、日期、数据完整性需用户负责。
- 基金、房产、保险、自动股息/拆股、税费、成本批次、精确投资组合收益率和 AI 分析未做完整实现；本版是以现金、股票、负债为核心的管理基础版。

## 隐私与同步
前端 GitHub Pages：`https://wongtszshan.github.io/Wealth-Management/`。
云端 Worker：`https://wealth-management-api.wangtszshan.workers.dev`。
独立 GitHub 私库：`wongtszshan/Wealth-Management-data`，加密文件 `finance.cloud.encrypted.json`。
- 浏览器账本保存在本机 localStorage，**未加密**；请只在信任的设备使用。
- 登录后由 Cloudflare Worker 进行 AES-GCM 加密并写入私库；Worker Secret 管理 GitHub Token、登录口令和加密密钥。**不是端到端加密**。
- 已有旧账升级时保留旧字段；本地与云端发现差异会暂停自动覆盖。本机录入新版资产时也会参与冲突检测。
- 建议升级前用「设置与同步 → 导出本地 JSON 备份」独立备份。不要修改或遗失 DATA_ENCRYPTION_KEY。
- 163 / OCBC 邮箱**未接入自动读取或转发**，避免扩大私人邮箱访问权限。银行账单采取按需手动导入。
- 图片和 PDF：仅选定页面在点击识别时传至 Worker 和所选 AI 模型商；PDF 原文件不会写入私库。识别结果需要人工复核。

## 使用节奏建议
1. 首次建立银行现金账户、现有美股与新加坡股持仓、负债，以及必要参考汇率。
2. 不定期导入消费流水；月底更新账户余额、股票估值和负债。
3. 在「财富报告」中完成月度自查清单并保存快照。
4. 每季度检视资产配置、资金目标、集中度、现金覆盖和历史净资产变化。

**注意**：报告和健康指标属于个人财务整理，不构成投资建议，不代表对账已由银行确认。
