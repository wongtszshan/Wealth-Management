# 澄理 · Wealth Management

个人财务与资产管理渐进式网页应用（PWA）。项目覆盖现金账户、现金管理类产品、证券账户、负债、收入支出、对账、财务目标和历史资产快照。

> **隐私原则**：公开仓库仅存放通用功能、数据结构、接口说明和示例。真实银行名称、银行卡尾号、证券持仓、贷款名称、资产金额、交易记录与账户关系，均不得写入公开代码、README、提交说明或示例文件。用户数据按授权存放在私有存储中。

## 主要功能

- **资产与负债**：记录不同币种的银行存款、现金管理类理财及负债余额；账户关联、负债本金还款、余额校对与审计记录。
- **证券账户**：券商账户为上级实体，内部包含多币种现金余额、证券持仓、买卖记录和分红记录。支持移动加权平均成本、已实现与未实现盈亏、手动估值及账户净值对账。
- **收支流水**：交易新增、编辑、银行账单 CSV / PDF / 图片导入、邮件通知粘贴解析、分类预算和月度对比。
- **辅助识别**：经用户主动授权，可将选定的账单或成交截图交给 AI 识别，进入待确认列表；不允许未经核对就修改真实持仓或负债。
- **财富报表**：SGD、CNY 汇总显示、参考汇率、历史净资产快照、财务目标、未来现金流及自查清单。
- **手机端 PWA**：响应式界面、交易卡片、离线界面缓存。

## 数据关系与核对规则

### 账户与交易

银行账户记录实际余额快照；交易流水记录资金进出并可关联账户。银行余额不会因上传不完整的流水而被再次自动扣减。

跨账户内部转账不计为额外收入或消费。账户余额与真实账单有差异时，使用「余额校对」记录差额、日期和原因，且校对差额不纳入消费统计。

### 贷款偿还

负债可以关联实际扣款账户。导入银行流水后，需要选择对应扣款记录并核实其中的本金、利息及费用；两项合计必须与真实扣款额一致。

仅经核实的**本金部分**减少未偿负债，利息及费用进入相应支出类别；银行现金仍以用户已录入的余额快照为准，避免双重扣减。系统防止同一流水重复关联，也会阻止旧于负债余额快照的还款再次扣减。

**限制**：普通扣款流水不一定含本息拆分，系统不能从总扣款额臆测本金；还款核对仍需人工确认。

### 证券账户与成交

券商账户统一管理账户净值、多币种现金、持仓和买卖历史。若已录入券商报告净值，财富总览将该券商账户作为一项整体资产计入一次；内部现金和证券市值用于结构展示与对账，**不得重复加总**。

对账区将报告净值、内部计算资产及差额统一到报告币种；单只证券与现金明细保留原币种。缺少汇率、现金或估值时明确提示数据不完整。

交易记录可录入买入、卖出及现金分红，按移动加权平均成本计算持仓、已实现盈亏、未实现盈亏。券商成交截图识别只采纳实际成交数量及成交均价，取消或未成交订单不入账。日期、费用和期初持仓日期需要人工核对。

**限制**：现阶段买卖记录不会自动更新手动填写的券商现金余额；完整的资金流水勾稽、未结算资金、保证金、企业行动、税费和汇率收益尚未全部覆盖。证券市价也不自动从行情服务更新。

## 数据与隐私

- 前端通过 GitHub Pages 提供静态 PWA。
- 用户账本由经过认证的 Cloudflare Worker 同步至独立私有存储；在服务器端加密。Worker Secrets 保存必要凭据，**不能**将其写入公开仓库。
- 浏览器本地数据保存在 localStorage，并非端到端加密；仅在可信设备上使用。
- 邮箱自动读取未接入。选定图片或 PDF 只有在主动点击「开始识别」时才会发送至后端及所选 AI 服务；原始文件不会作为公开代码提交。
- 数据结构升级保留旧账字段，检测到本地与远端差异时先执行冲突保护。建议在重要录入前导出本地 JSON 备份。
- 任何文档、UI 示例与代码演示使用泛化虚构名称，例如「银行账户 A」「贷款账户 B」「券商账户」，而不使用真实用户金融机构或资产名称。

## 维护与测试

1. 在开发过程中检查 JavaScript 语法，以及桌面和手机端布局。
2. 对金额、币种、汇率、重复交易、负债本金与利息拆分进行业务规则测试。
3. 提交公共仓库前检查代码、文档及示例，不含个人资产、账户标识、真实交易与密钥。
4. 更新 PWA 缓存版本，并验证发布版本及云端同步逻辑。
5. 真实数据与示例数据严格隔离，不以未经确认的 AI 识别结果替换原始账本。

**当前公开前端版本：v2.1.9。** 本项目用于个人财务整理，不构成投资建议或银行对账确认。


### 内部转账与待核查

新版 CSV 优先核对明确收支字段与金额符号；方向不明或互相冲突时保留待核查。内部划转要求两个不同的已建资产账户、明确流水方向及双方金额。历史未关联转账按待核查显示，原始记录不自动迁移；双方账单由用户核对关联，手续费另记支出，余额快照不自动调整。
