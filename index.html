数据与隐私
数据默认保存在此浏览器的本地存储中
本机缓存未加密，清除网站数据可能丢失记录。使用公用设备时不要录入敏感账目。私库虽设为 Private，但并非端到端托管安全机制的替代；云端备份由 Cloudflare Worker 加密后写入 GitHub 私库。
功能与限制

已支持：双币种、人工记账、CSV 导入、通知邮件解析、人工复核、分类对比、预算、账户昵称、加密备份。
尚未支持：OCBC 邮箱自动授权、银行卡 API、自动实时余额、跨设备实时合并。
