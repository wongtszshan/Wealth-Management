① 导入银行文件

支持 CSV 文本文件（UTF-8）、银行通知邮件文本。文件中的字段需要你复核；复杂银行专用格式可能需要调整列映射。

② 招行截图批量收集

可一次选多张截图，记录导入批次。当前版本尚未连接图片识别 AI，因此不会假称截图已解析。建议在交易页面补录或导出结构化账单。

③ 待确认交易
复核日期、金额、币种、分类；自动匹配可能的重复交易
图片识别、银行 API 直连与自动读取 OCBC 邮箱不包含在当前版本中。请勿上传含身份证号码、完整银行卡号、网银密码的未脱敏截图到外部 AI 服务。
月度消费对比
包含上月为零、本月新增的消费类别
各分类金额变化

上个月为零、本月大于零时显示「新增金额」，不计算无意义的百分比；数据可能受未上传的交易影响。

本月分类预算
同币种预算独立管理；按当前消费计算使用率
储蓄目标

设置每月期望储蓄额，用收入减支出估算当月结余；此值不等于银行账户余额。

账户管理
不需要真实卡号，使用昵称或尾号识别
账户初始余额与记账交易是两个不同概念。本版不自动推导银行真实余额，以免遗漏交易造成误判。
云端私库 · 加密同步
GitHub 私库只保存加密 JSON，不保存明文银行账目
连接方式：使用仅授权 Wealth-Management-data 仓库 Contents 读写权限的 Fine-grained Token。Token 只保留在当前页面内存中，刷新后需重填。密码短语用于浏览器端加密，请务必自行保存；遗失则无法解密备份。
尚未连接云端
数据与隐私
数据默认保存在此浏览器的本地存储中
本机缓存未加密，清除网站数据可能丢失记录。使用公用设备时不要录入敏感账目。私库虽设为 Private，但并非端到端托管安全机制的替代；本版通过浏览器端加密降低明文暴露。
功能与限制

已支持：双币种、人工记账、CSV 导入、通知邮件解析、人工复核、分类对比、预算、账户昵称、加密备份。
尚未支持：图片 OCR / AI 识别、OCBC 邮箱自动授权、银行卡 API、自动实时余额、跨设备实时合并。
